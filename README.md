# منصة أحمد الرمادي | ملك اللغة العربية

منصة تعليمية عربية متكاملة (RTL) لإدارة التعليم الإلكتروني للصفوف الدراسية الأربعة، مبنية بـ React + TypeScript + Tailwind CSS + Express + Supabase (PostgreSQL / RLS / Storage) مع وضع معاينة محلي جاهز عبر SQLite.

---

## المميزات الأساسية
1. **هوية بصرية عربية فاخرة (RTL)**: الأسود الفاخر، الكحلي الداكن، والذهبي المعدني، مع الصورة الرسمية للأستاذ أحمد الرمادي وشعار متجهي (Vector) مخصص بنسختين (أيقونة + أفقي) متضمن في المنصة وشهادات PDF.
2. **أربعة صفوف دراسية معزولة تمامًا**:
   - الصف الثالث الإعدادي
   - الصف الأول الثانوي
   - الصف الثاني الثانوي
   - الصف الثالث الثانوي
   *(كل طالب يرى امتحاناته وفيديوهاته ونتائجه ولوحات الشرف وإشعاراته فقط دون تداخل بين الصفوف).*
3. **نظام حسابات آمن ومنع التكرار**:
   - قيود فعلية على قاعدة البيانات تمنع تكرار **الاسم الرباعي المُطبع** أو **رقم الهاتف**.
   - السماح بتسجيل الدخول من عدة أجهزة في وقت واحد عبر جلسات مستقلة (`user_sessions`).
   - نسيان كلمة المرور: لا يطلع المدرس على كلمة المرور القديمة مطلقًا، بل يعين كلمة مرور مؤقتة جديدة (يدويًا أو تلقائيًا) ويُجبر الطالب على تغييرها فور تسجيل الدخول.
4. **نظام امتحانات صارم بدون بنك أسئلة**:
   - المدرس ينشئ أسئلة واختيارات كل امتحان بشكل مستقل تمامًا داخل الامتحان نفسه.
   - لا تُرسل الإجابات الصحيحة (`is_correct`) إلى متصفح الطالب مطلقًا.
   - مؤقت الامتحان وحفظ الإجابات التلقائي والتصحيح تتم على الخادم بتوقيت UTC مع إغلاق وتصحيح تلقائي عند انتهاء الوقت.
5. **المجموع التراكمي ولوحات الشرف**:
   - مجموع تراكمي مفتوح دون حد أقصى 100 (مثلاً `200/200` أو `700/700`).
   - لا تُضاف درجات صفرية للامتحانات التي لم يؤدها الطالب.
   - لوحة شرف لكل امتحان + لوحة شرف تراكمية لكل صف تراعي عدد الامتحانات والنسبة المئوية والسرعة (`duration_ms`).
6. **الفيديوهات، الشارات، الشهادات، والجدولة**:
   - دعم روابط الفيديو المجانية بلا حدود (**YouTube غير مدرج** / **Google Drive** / **Vimeo** / MP4 مباشر) مع جلب الصورة المصغرة تلقائيًا، بالإضافة لرفع الملفات الصغيرة مباشرة عبر الخادم مع بث مقطعي (`HTTP Range 206`) وتصنيفها (الصف → الوحدة → الدرس).
   - شارات تلقائية ومخصصة بدون تكرار.
   - إصدار شهادات تقدير بصيغة **PDF عربي حقيقي (RTL)** عبر `pdf-lib` وخطوط `Noto Naskh Arabic`.
   - جدولة نشر الفيديوهات والامتحانات بتوقيت `Africa/Cairo` وتنفيذها تلقائيًا على الخادم.

## متطلبات التشغيل المحلي والتشغيل من GitHub (Node.js 20+ / 22+)

1. استنساخ المستودع من GitHub وتثبيت الاعتماديات:
   ```bash
   git clone <YOUR_GITHUB_REPO_URL>
   cd <REPO_FOLDER>
   npm install
   ```
2. إنشاء ملف `.env` انطلاقًا من `.env.example`:
   ```bash
   cp .env.example .env
   ```
3. تشغيل المنصة للتطوير:
   ```bash
   npm run dev
   ```
   يعمل الخادم والواجهة على المنفذ `3000`.
   > ملاحظة: إذا لم تُضَف مفاتيح Supabase بعد، تعمل المنصة تلقائيًا على قاعدة بيانات SQLite محلية في `.data/ramady_platform.sqlite` وتخزين محلي في `.data/uploads/` لتجربة واختبار جميع المزايا فورًا.

4. تشغيل الاختبارات الشاملة:
   ```bash
   npm test
   ```
5. فحص الأنواع والبناء الإنتاجي:
   ```bash
   npm run lint
   npm run build
   npm start
   ```

## تهيئة قاعدة البيانات الخارجية على Supabase (إلزامي للإنتاج)

لربط المنصة بقاعدة بيانات Supabase الخارجية الدائمة:

1. أنشئ مشروعًا جديدًا على [Supabase](https://supabase.com).
2. من لوحة Supabase افتح **SQL Editor** ونفّذ الملفات التالية بالترتيب:
   - `supabase/migrations/001_initial_schema.sql` (إنشاء الجداول العشرين والقيود الفريدة والجزئية).
   - `supabase/migrations/002_rls_policies.sql` (تفعيل سياسات أمان الصفوف RLS على جميع الجداول).
   - `supabase/migrations/003_seed_defaults.sql` (إدراج الأدوار والصفوف الأربعة والشارات الأساسية).
   - `supabase/storage_setup.sql` (إنشاء حاويات التخزين `videos`, `thumbnails`, `question-images`).
3. من **Project Settings → API** انسخ القيم وأضفها إلى **Secrets / Environment Variables**:
   - `SUPABASE_URL`
   - `SUPABASE_ANON_KEY`
   - `SUPABASE_SERVICE_ROLE_KEY` (يُستخدم على الخادم فقط ولا يُمرر للمتصفح أبدًا).
4. أضف متغيرات الأمان على الخادم:
   - `ADMIN_ACCESS_CODE` (الرمز السري للدخول لغرفة إدارة المدرس `/admin-gate` — يُطلب في كل مرة يتم فيها الدخول إلى غرفة الإدارة أو العودة إليها).
   - `CRON_SECRET` (مفتاح سري لحماية مسار تنفيذ الجدولة `POST /api/cron/publish`).

> إذا لم يُضف `ADMIN_ACCESS_CODE` في البيئة، تتيح صفحة `/admin-gate` في أول تشغيل فقط تعيين رمز الإدارة من الواجهة ويُحفظ مشفرًا (`scrypt`) في جدول `platform_settings`.

## حدود الباقة المجانية وتوصيات التشغيل

- **Supabase Free Tier**:
  - قاعدة البيانات: `500 MB` (يكفي آلاف الطلاب والنتائج).
  - التخزين (`Storage`): `1 GB` للفيديوهات والصور المصغرة.
  - النقل الشهري (`Bandwidth / Egress`): `5 GB` شهريًا.
  - **توصية مهمة**: اضغط الفيديوهات بصيغة `MP4 (H.264 - 720p)` لتقليل الحجم والحفاظ على حصة الباندويث المجانية، أو قم بترقية الباقة عند زيادة عدد المشاهدات.
- **النشر الإنتاجي (Cloud Run / Node / VPS / Vercel)**:
  - لأفضل أداء مع رفع الفيديوهات والـ Cron الداخلي (`node-cron`)، يُنصح بتشغيل الخادم الموحد عبر:
    ```bash
    npm run build && npm start
    ```
  - في بيئات Serverless، اضبط Cron Job خارجي كل دقيقة يستدعي `POST /api/cron/publish` مع ترويسة `x-cron-secret: <CRON_SECRET>`.
